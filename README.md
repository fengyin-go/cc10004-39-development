# 数据洞察分析工作台

面向多源数据接入、交互式查询分析、可视化看板搭建、分析报告生成与数据服务编排的数据洞察分析工作台。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/              统一请求封装
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/          每个业务模块一组接口
│   ├── app/services/         业务规则与状态流转
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 候选键来源解释器（查询缓存增强）

入口：查询缓存页右上角「候选键来源解释器」，路由 `/cache/explainer`；接口前缀
`/api/cache/explainer`，实现位于 `backend/app/services/cache_explainer.py`。

它把一次交互查询请求编码成缓存候选键，并以一棵键构成树分步说明五段来源：

1. **来源模块**：请求来自哪个交互模块，用于跨模块核对本轮结果身份。
2. **表达式规范化**：注释剥离、空白折叠、引号外大小写归一、尾部分号去除，每步留「变更前/后」证据。
3. **参数规范化**：参数名命中 token/secret/password/凭证/密码/密钥 等模式时，值在编码前整体掩码
   （原始值不入库、不进解释树），随后按键名排序、标量类型归一；编辑任何样本参数都会让树叶实时重算。
4. **数据集版本锚定**：数据集名与版本号同时入键，数据刷新后旧键不会被误命中。
5. **策略代次**：策略修订一次代次 +1，旧代次解释树随原请求封存（证据冻结，重算指纹可验完整性）。

五段证据拼成确定性规范 JSON → SHA-256 完整指纹 → 取前 8 位作为候选键。短前缀可能碰撞：
不同原始请求落到同一候选键时，系统逐段对照两份规范化证据，以完整指纹判定身份并**阻断错误复用**。
缓存槽填充/签认在锁内同时核验代次与指纹，同请求重复操作幂等；并发修订演示用真实线程复现
「填充先抢锁 / 修订先抢锁」两种交织，证明旧解释在任何时序下都拿不到写入许可。

页面提供八个操作面板：请求工作台、结论条、键构成树、碰撞逐段对照、策略代次与冻结、
缓存槽授权事件、跨模块身份核对、并发线程演示与树叶台账。

## 约定

- 每个模块的前端页面在 `frontend/src/views/<模块>/index.vue`，后端接口在
  `backend/app/routers/<模块>.py`，业务规则在 `backend/app/services/<模块>.py`。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。
